## 🚀 Installation

### Prerequisites

To run and edit these MIPS assembly programs, you'll need a MIPS simulator or assembler. Recommended options:

- **MARS (MIPS Assembler and Runtime Simulator)** - [Download](http://courses.missouristate.edu/kenvollmar/mars/)
- **SPIM** - [Download](http://spimsimulator.sourceforge.net/)
- **QtSpim** - GUI version of SPIM
- **MIPS Assembly Online** - [Web-based simulator](https://github.com/bilonenko/mipsasm)

### Setup Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/H0NEYP0T-466/mips_workbench.git
   cd mips_workbench
   ```

2. **Install a MIPS Simulator**
   
   **For MARS (Recommended):**
   - Download Mars.jar from the official website
   - Ensure you have Java Runtime Environment (JRE) installed
   - Run: `java -jar Mars.jar`

   **For SPIM (Linux/Mac):**
   ```bash
   # Ubuntu/Debian
   sudo apt-get install spim
   
   # macOS
   brew install spim
   ```

3. **Open any `.asm` file in your MIPS simulator**

## ⚡ Usage

### Running Programs in MARS

1. Launch MARS: `java -jar Mars.jar`
2. Open a file: `File > Open` and select any `.asm` file
3. Assemble the program: `Run > Assemble` (F3)
4. Execute: `Run > Go` (F5)
5. View output in the console window

### Running Programs in SPIM

```bash
spim -file LAB_1_TASK#1.asm
```

## 📦 Dependencies & Packages

### Runtime Dependencies

This is a pure MIPS Assembly language project with no external package dependencies. The programs require only a MIPS simulator or assembler to run:

**Required:**
- **MARS (MIPS Assembler and Runtime Simulator)** or **SPIM** - MIPS simulator for executing assembly code
- **Java Runtime Environment (JRE)** - Required if using MARS (Java-based simulator)

**Optional Tools:**
- **QtSpim** - GUI version of SPIM for easier debugging
- **Text Editor/IDE** - Any text editor for viewing and editing `.asm` files (VS Code, Sublime Text, Notepad++, etc.)

_Note: No external dependencies detected from package managers. This is a standalone assembly language project._
